## Featured Projects

### CodeGuard AI

A full-stack debugging assistant for Python repositories built using **React, FastAPI, LangGraph, Groq API, and Python AST**.

* Uses a multi-agent workflow to analyse Python repositories
* Combines AST analysis, stack traces, and static-analysis signals
* Identifies suspicious files and explains likely root causes
* Generates suggested corrections and corrected code
* Includes repository metrics, execution traces, suspect rankings, and analysis history
* FastAPI backend deployed using Google Cloud Run
